# Repository maintenance

- Continue development in this Git repository and preserve its existing history. Inspect status and diff before editing; do not discard unrelated changes.
- Keep commits focused and descriptive. Run `npm test`, `npm run data:audit`, and `npm run build` before committing application changes. Commit only after checking the staged diff.
- Do not force-push, rewrite published history, or overwrite remote changes. Push only when the user authorizes it.
- Never commit personal ranking exports, diagnostic artifacts, credentials, environment files, dependencies, build output, or raw source caches.
- Preserve third-party data and portrait attribution. New artwork needs a recorded source and applicable permission; do not infer unrestricted redistribution from download availability.
- Keep README and the relevant data, asset, and QA reports consistent with the implementation. Clearly distinguish current verification from historical results.
