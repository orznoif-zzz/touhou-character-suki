## 接入流程

1. 取得作者原始说明，分别确认网页托管、仓库分发、结果 PNG 传播和署名要求；将证据保存到素材清单。
2. 优先选同一作者系列，按角色稳定 ID 建立映射；变体只选择一张，不新增身份。
3. 将获准文件放入 `public/assets/characters/{characterId}.png`，更新角色 `image`（相对于部署根目录）以及素材清单；不要只因文件可下载就导入。
4. 补全 `AssetRecord` 的 characterId、path、author、source、permission、credit。当前清单见 `data/assets.json`，为空。
5. 核对图片是否存在、大小、署名位置与作者要求。只有明确允许海报再传播时，才扩展当前纯文字 Canvas 海报渲染器绘制角色图片。

当前缺图名单即 `src/data/characters.json` 的全部 203 个角色。图片加载失败由 `CharacterArtwork` 自动回退，后续无需修改排序逻辑。

## 立绘取景
顶部“立绘”菜单集中提供开关、全身（100%）/半身（170%）/近景（260%）预设，以及 100%–300% 连续缩放。取景全站同步并保存在浏览器，不影响排序存档。放大以图片顶部中心为锚点，仅在原图片区域内裁切；缺图时名字占位不缩放。近景来自同一张全身图，特殊姿势与透明留白可能影响脸部位置，可用滑杆微调；不是额外的头图素材。
